## 🔥 핵심 도구

### 스마트 화재경보 자동 배치 엔진
> *전체 층의 연기/열 감지기를 몇 초 안에 자동으로 배치*

- 실 규모, 용도, 천장 높이 분석
- **NFPA 72** 기준 자동 적용
- 보조 천장 상단 배치 자동 처리
- 루프 배선 + 장치 번호 자동 생성
- 제출 가능한 **단선도** 자동 생성

**효과:** 기존 2일 작업이 2분으로 단축

---

### CCTV 시야 범위(FOV) 자동화
> *모든 카메라의 정확한 시야 범위를 즉시 가시화*

- 카메라 각도, 범위, 방향 자동 분석
- 정확한 시야 범위 해치 생성
- 모든 카메라 고유 번호 자동 태깅
- 각 카메라의 데이터 아웃렛 매핑
- 주차장 센서 + LED 자동 배치

**효과:** 수동 FOV 작성 완전 제거

---

### 표준층 복제 도구
> *한 층을 설계하고 30층에 자동 복제*

- 모든 전기 회로 파라미터 유지
- 패널 스케줄 자동 생성/연결
- 뷰 표현 및 주석 기준 유지
- 연결된 Revit 모델 지원

---

### 케이블 트레이 자동 라우팅
> *복잡한 기하학을 따라 케이블 트레이 네트워크 자동 생성*

- 그리드 패턴 케이블 트레이 (접속 부품 포함)
- **터널 팔로워** — 곡선 터널 기하학 자동 정렬
- 장치 자동 배치 (선형 및 곡선)
- CAT6 길이 자동 검증 (90m 초과 플래그)

---

### 지능형 데이터 아웃렛 배치
> *모든 네트워크 장비를 읽고 데이터 아웃렛 자동 배치*

- 천장/벽면 탑재 자동 처리
- 장비 파라미터 및 태깅 자동 입력
- 층별 배포 실 기준으로 자동 분류
- 입찰 제출 가능한 스케줄 생성
